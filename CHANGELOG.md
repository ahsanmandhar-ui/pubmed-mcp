# Changelog

All notable changes to pubmed-mcp are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-10-17

### Added
- Redesigned README with badges, tool tables, guarantees, and client setup examples.
- `docs/images/` placeholder for architecture diagram and example response screenshot.
- Offline CI workflow that runs the test suite on push and pull request.
- `CHANGELOG.md` and `CONTRIBUTING.md`.

### Changed
- Repository description set to: "Minimal, auditable MCP server for PubMed via NCBI E-utilities. Returns only what NCBI returns; missing fields are flagged, never inferred. Built for evidence synthesis and systematic reviews."
